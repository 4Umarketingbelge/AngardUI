# AngardUI

Панель персонажа для World of Warcraft: Forever (клиент 1.60.1, Interface 16001) со здоровьем и маной и симуляцией «медицины»: пульс, температура, шаги. Аддон только показывает информацию и ничего не делает в игре за игрока.

*A character panel addon for World of Warcraft: Forever with health and mana bars and a simulated "medical" readout (pulse, temperature, steps). Display only. Locales: ruRU, enUS.*

Статус: версия 1.1.0. Версия 1.0 запускалась в игре; правки 1.1 проверены вне игры на заглушке API.

## Что на панели

| Блок | Что показывает |
| --- | --- |
| Карточка персонажа | эмблема фракции, имя цветом класса, уровень, шаги, класс и специализация, свод правил, время на уровне, деньги, профессии с полосками прогресса |
| Портрет | анимированный 3D-портрет персонажа |
| Пульс | число ударов в минуту и бегущая кардиограмма, частота пиков равна пульсу |
| Здоровье и мана | две полоски с числами: здоровье и ресурс класса (мана, ярость, энергия) |
| Температура | термометр, значение в °C или °F, статус: норма / знобит / жар / перегрев |
| Гильдия | офицеры в сети; клик по имени открывает строку шёпота |
| Питомец | портрет активного питомца, обесцвеченный, если питомец мёртв |

Любой блок отключается в настройках, остальные сдвигаются без пустых мест.

Стандартная рамка игрока (портрет, здоровье, мана) по умолчанию скрывается, потому что панель её заменяет. Вместе с ней скрываются привязанные к ней элементы: рамка питомца и значки отдыха и боя. Отключается галочкой «Скрывать стандартную рамку игрока» в разделе «Общее».

Рамку цели аддон не двигает. Если она перекрывает панель, передвиньте её один раз: Esc → «Режим редактирования».

## Правила Blizzard

- Только официальный Lua API аддонов, без внешних программ.
- Никакой автоматизации: аддон ничего не нажимает, не отправляет сообщений в чат и не шлёт аддон-сообщений.
- Все фреймы панели обычные, незащищённые. Единственное действие над защищённым фреймом — скрытие стандартной рамки игрока штатным драйвером состояния, и только вне боя.
- Код открыт, аддон бесплатный, без рекламы.

## Установка

1. Закройте игру.
2. Скачайте репозиторий (Code → Download ZIP) и положите папку с файлами в `World of Warcraft\_forever_\Interface\AddOns\` под именем `AngardUI`.
   Должно получиться `...\_forever_\Interface\AddOns\AngardUI\AngardUI.toc`.
3. Запустите игру, на экране выбора персонажа нажмите «Модификации» и включите AngardUI.

## Команды

| Команда | Действие |
| --- | --- |
| `/angard` | открыть окно настроек |
| `/angard show` / `hide` | показать / скрыть панель |
| `/angard lock` | заблокировать или разблокировать позицию |
| `/angard reset` | вернуть панель в левый верхний угол |
| `/angard debug` | показать последнюю перехваченную ошибку |

Настройки также открываются кнопкой у миникарты (левая кнопка мыши — настройки, правая — показать или скрыть панель, перетаскивание — передвинуть кнопку) и из «Настройки → Модификации → AngardUI».

## Файлы

| Файл | Что внутри |
| --- | --- |
| `Config.lua` | все коэффициенты симуляции, таблица климата зон, размеры, иконки, настройки по умолчанию |
| `Locales.lua` | ruRU и enUS |
| `Core.lua` | события, таймеры, сохранённые данные, раскладка блоков, слэш-команда |
| `Simulation.lua` | модель пульса и температуры |
| `Tracker.lua` | шаги и время на уровне |
| `Blocks\*.lua` | семь блоков панели, по одному на файл |
| `Options.lua` | окно настроек и регистрация в меню игры |
| `Minimap.lua` | кнопка у миникарты |

## Данные

- `AngardUIDB` (на аккаунт): настройки и позиция панели.
- `AngardUICharDB` (на персонажа): шаги и время на текущем уровне.

## Как устроена симуляция

Показатели плавно тянутся к целевому значению и слегка «дышат» случайным шумом. Что на что влияет и с какой силой — в `Config.lua`, разделы `pulse`, `stress`, `temp`. Климат зон задан таблицей `zones` по AreaID.

В Forever действуют те же ограничения для аддонов, что и в Midnight: в бою часть значений (например, здоровье) приходит «секретной», и её нельзя сравнивать или складывать. Симуляция такие значения не трогает: берёт последнее известное здоровье и добавляет стресс за каждый полученный удар. Полоски здоровья и маны передают их игре как есть, без вычислений.
